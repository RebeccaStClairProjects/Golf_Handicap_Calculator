Welcome to the new Polo Park East Handicap Tracker

Your digital tool for maintaining accurate, up-to-date golfer records.


Getting Started

Use the navigation menu above to access the main features of the system:

  • Add Golfer – Register a new golfer in the system.
  • Add Round – Record a new round of play for an existing golfer.
  • Update Handicap Metrics – Adjust how handicaps are calculated, including course information, stroke limits, and provisional round settings.
  • Print Member Handicaps – Generate and print up-to-date handicap summaries for all registered golfers.

Tips for Best Results

  • Before adding a new golfer, use the Golfer Search feature to ensure the player isn’t already in the system.
  • Enter names exactly as they appear on official records to ensure accurate matches.
  • Follow on-screen prompts carefully; each page will guide you through the required steps.

This system was designed to make managing golfer information simple, accurate, and convenient — just like the game itself should be.
